# husnainh-dev.github.io

Personal portfolio of **Husnain Haider**: Sr. Software Developer at Rolustech, Lahore. Full-stack developer (Laravel, Node.js, React, Vue, Ruby on Rails) moving into AI engineering.

🔗 **Live:** https://husnainh-dev.github.io

## Stack
Plain HTML, CSS and a small amount of vanilla JavaScript. There is no framework, no build step, and no dependencies.

```
.
├── index.html   # single-page site (hero, about, skills, projects, experience, contact)
├── styles.css   # dark theme, responsive layout
├── script.js    # mobile nav, scroll reveal, footer year
├── assets/      # photo.jpg (600×600 profile photo)
└── .nojekyll    # serve files as-is on GitHub Pages
```

## Run locally
```bash
# any static server works
python3 -m http.server 8000
# then open http://localhost:8000
```

## Deploy (GitHub Pages)
1. Create a public repo named **`husnainh-dev.github.io`**.
2. Push these files to the `main` branch.
3. In **Settings → Pages**, set the source to *Deploy from a branch* → `main` / `root`.
4. The site will be served at https://husnainh-dev.github.io

## Customising
The content comes from my CV. Edit `index.html` directly to update experience, projects or skills. If the `ecomerence` or `portfolio` repos become public, add repo/demo links to their cards.
