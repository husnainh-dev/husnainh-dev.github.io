03 Projects

AI engineering

AI-Powered Code Review Platform

Developer productivity & DevOps

An LLM-powered platform that analyzes pull requests across GitHub, GitLab and Bitbucket automatically and posts AI-generated review comments inside developers' existing workflows.

  • Prompt pipelines that combine PR metadata, code diffs, repository guidelines (CODEREVIEWPROMPT.md) and Jira/Redmine issue context to produce reviews that take the linked ticket into account.
  • Webhook-driven automation with signature verification, deduplication and retries for reliable CI/CD integration.
  • MCP-based integration services for GitHub, GitLab, Bitbucket, Jira and Redmine.
  • FastAPI backend with MySQL analytics for review metrics, repository activity and review quality.
  • Review standards load per repository, so review behavior can change without redeploying the service.
